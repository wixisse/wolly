# Wolly - Desktop Wallpaper App

A beautiful desktop wallpaper application for Linux with a modern UI, wallpapers from Wallhaven, and smooth animations.

## Download

Get the latest AppImage from [GitHub Releases](https://github.com/wixisse/wolly/releases).

Download `Wolly-0.0.1.AppImage`, make it executable, and run:
```bash
chmod +x Wolly-0.0.1.AppImage
./Wolly-0.0.1.AppImage
```

## Clone & Run

```bash
git clone https://github.com/wixisse/wolly.git
cd wolly
npm install
npm run dev
```

## Build AppImage

```bash
npm run electron:build:linux
```

The AppImage will be in the `dist` folder.
